    Metadata & compliance

    Sections & logic

    Use drag-and-drop to arrange sections (Welcome, Segment Split, Recovery) and define rules with respondent attributes + scores.

  • 3
    Question detail

    Mix question types with validation (min/max, regex, required). Add help text + tooltips for accessibility.

  • 4
    Preview & approvals

    Preview desktop/mobile with screen-reader audio, then request admin sign-off to unlock “Publish”.
